# OSPO – Osma Potes Abogados · Sitio web corporativo

Sitio institucional de la firma de abogados **OSPO – Osma Potes Abogados** (Bogotá): inicio, nosotros, servicios, equipo y contacto.

**Sitio en vivo:** [osmapotes.com.co](https://osmapotes.com.co)

- Diseño y dirección de arte alineados a la marca de la firma
- Sitio estático de 5 páginas en HTML, CSS y JavaScript, adaptable a móvil
- Proyecto de [Nómada Estudio Digital](https://nomadaestudio.digital)

---
